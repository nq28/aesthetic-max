### 2. Build File Cài Đặt Android APK

Thư mục `aesthetic-max/android` đã được tích hợp sẵn toàn bộ mã nguồn Native Android (Capacitor Native Bridge).

#### Cách 1: Sử dụng Android Studio (Khuyên dùng)
1. Tải và mở **Android Studio**.
2. Chọn **Open Project** và chọn thư mục:
   `C:\Users\Admin\.gemini\antigravity\scratch\aesthetic-max\android`
3. Chờ Android Studio đồng bộ Gradle và tải Android SDK tự động.
4. Chọn menu **Build** > **Build Bundle(s) / APK(s)** > **Build APK(s)**.
5. File `app-debug.apk` sẽ được tạo tại:
   `android/app/build/outputs/apk/debug/app-debug.apk`

#### Cách 2: Build APK trực tiếp qua Terminal (Yêu cầu JDK 17/21 & Android SDK)
```bash
cd aesthetic-max
npm run build
npx cap sync android
cd android
./gradlew assembleDebug
```
